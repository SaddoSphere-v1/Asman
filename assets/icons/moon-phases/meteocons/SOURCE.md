# Meteocons (Bas Milius) — animated + static Moon phases, Sun, stars, eclipse, in 4 styles

- **Source:** https://github.com/basmilius/meteocons (@meteocons/svg, @meteocons/svg-static 0.1.0)
- **License:** MIT (https://opensource.org/licenses/MIT)
- **Attribution / credit line:** Meteocons by Bas Milius, MIT
- **Quality tier:** A

Animated SVGs use embedded CSS/SMIL, no JS. Styles: fill (colour), flat, line, monochrome. Great for a living Panchanga header (moon phase, sunrise/sunset, hora clock).
