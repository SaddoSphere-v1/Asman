# Astronomicon astrological font (Roberto Corona)

- **Source:** https://astronomicon.co (bundled with Astrolog: https://github.com/CruiserOne/Astrolog/tree/master/font)
- **License:** SIL OFL 1.1 (Reserved Font Name "Astronomicon") (https://scripts.sil.org/OFL)
- **Attribution / credit line:** Astronomicon by Roberto Corona, SIL OFL 1.1
- **Quality tier:** A

192 glyphs mapped onto ASCII letters/digits (planets, signs, aspects, asteroids, Uranian points). Open preview/index.html to see the key map rendered; the font is designed to blend with modern UI type.
