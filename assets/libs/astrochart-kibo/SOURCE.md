# AstroChart (Kibo) — dependency-free SVG natal/transit wheel renderer with built-in glyph paths

- **Source:** https://github.com/Kibo/AstroChart (v2.0.1; successor: https://github.com/AstroDraw/AstroChart, TypeScript)
- **License:** MIT (https://opensource.org/licenses/MIT)
- **Attribution / credit line:** Matheus Alves (Kibo), AstroChart, MIT
- **Quality tier:** A

All planet/sign symbols are drawn as SVG path code inside svg.js — extractable as a glyph library. Colours/sizes are configurable via settings.js. The wheel can be adapted to a sidereal zodiac by rotating the sign ring by the ayanamsa.
