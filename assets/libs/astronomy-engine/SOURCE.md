# Astronomy Engine (Don Cross) — Sun/Moon/planet positions, phases, rise/set, eclipses; single browser file

- **Source:** https://github.com/cosinekitty/astronomy (npm astronomy-engine 2.1.19)
- **License:** MIT (https://opensource.org/licenses/MIT)
- **Attribution / credit line:** Astronomy Engine by Don Cross, MIT
- **Quality tier:** A

±1 arcminute, no data files, 116 KB — enough for a standalone HTML panchanga/kundali (tropical → sidereal via ayanamsa; lunar nodes via SearchMoonNode or a mean-node formula). Swiss-Ephemeris-grade alternatives are listed in the catalog.
