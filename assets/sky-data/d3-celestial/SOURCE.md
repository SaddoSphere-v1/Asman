# d3-celestial star map library + sky data (stars to mag 6, constellations, Milky Way, planets)

- **Source:** https://github.com/ofrohn/d3-celestial (v0.7.35)
- **License:** BSD-3-Clause (https://opensource.org/licenses/BSD-3-Clause)
- **Attribution / credit line:** Olaf Frohn, d3-celestial (BSD-3-Clause); data derived from HYG, Stellarium and IAU sources (see data/readme.md)
- **Quality tier:** A

Everything needed for an in-browser sky chart: ecliptic/equatorial grids, zodiac band, Milky Way outline, 27 nakshatra boundaries can be drawn as 13°20′ ecliptic sectors on top. stars.8.json (5 MB) and stars.14.json (15 MB) are upstream if deeper zoom is needed.
